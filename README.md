A clean, lightweight Single Page Application (SPA) for managing contacts directly in the browser. Built purely with Vanilla JavaScript and TailwindCSS. This project demonstrates solid fundamentals in DOM manipulation, client-side state management, and modern responsive UI design.

---

## 🚀 Key Features

* **Full CRUD Operations:** Easily add, view, edit, and safely delete contacts.
* **Live Search:** Instantly filter your contact list in real-time.
* **Trash Management (Soft Delete):** Move items to the bin with options to restore or permanently delete.
* **Data Persistence:** Utilizes browser `localStorage` to keep your data safe even after a page refresh.
* **Responsive UI:** Optimized for seamless usage across desktop and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Vanilla JavaScript (ES6+)
* **Styling:** TailwindCSS
* **Deployment:** Vercel
